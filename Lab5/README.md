# Лабораторная работа 5: Агрегация и композиция

## Связи между объектами

- `Course` владеет `topics_`: `std::vector<std::string>` хранит темы по значению.
  Это композиция - темы создаются и уничтожаются вместе с курсом.
- `Course` хранит `Professor*`, но не удаляет профессора. Это агрегация: курс
  только использует профессора.
- `Student` хранит `std::vector<Course*>`, не удаляет курсы и не добавляет один
  и тот же указатель повторно. Это агрегация.

В `main` все объекты создаются на стеке. Профессорами владеет
`std::vector<Professor>`: контейнер содержит объекты по значению и автоматически
уничтожает их при выходе из `main`. Перед созданием курсов вызывается `reserve(2)`,
поэтому добавление двух профессоров не перемещает их и указатели в курсах остаются
действительными. Курс не делает `delete professor_`, потому что владельцем является
контейнер, а не курс.

`getTopics()` возвращает константную ссылку, чтобы не копировать вектор и не дать
вызывающему коду изменить темы в обход `Course::addTopic`.

## Сборка и запуск

```powershell
g++ -std=c++17 -Wall -Wextra Professor.cpp Course.cpp Student.cpp main.cpp -o lab5.exe
.\lab5.exe
```
