# Лабораторная работа 6: Наследование

## Иерархия

- `Student` хранит общее имя и список `Course*`.
- `BudgetStudent` добавляет стипендию.
- `PaidStudent` добавляет годовую стоимость обучения.
- `ForeignStudent` добавляет страну и возвращает фиксированную стоимость обучения
  `300000` без отдельного поля оплаты.

Базовые поля не дублируются в наследниках: каждый производный объект уже содержит
базовую часть `Student`. Конструкторы наследников вызывают `Student(name)` в списке
инициализации. `Course` и `Student` содержат только указатели на связанные объекты,
не владеют ими и ничего не удаляют.

## Невиртуальные методы и эксперименты

По требованию задания `getStatus`, `getTuition` и `getScholarship` не являются
виртуальными. Поэтому вызов этих методов через `Student*` привязывается статически к
`Student` и возвращает базовые значения: статус `Student` и нулевые суммы. Это
показано первым блоком программы и экспериментом 2: `getScholarship()` существует в
`Student`, поэтому код компилируется, но сумма через `Student*` равна нулю.

В эксперименте 1 метода `getScholarship()` в `Student` не было бы вовсе, поэтому
вызов через `Student*` не скомпилировался бы. Правильная динамическая диспетчеризация
появится после объявления методов `virtual` в следующей работе. Значения конкретных
наследников дополнительно выводятся напрямую, чтобы показать их реальные поля.
