# Лабораторная работа 4: Владение ресурсами и правило трёх

В работе реализован класс `Matrix`, владеющий динамически выделяемой двумерной
матрицей целых чисел. Класс продолжает возможности предыдущей работы и добавляет
корректное копирование объектов.

## Реализовано

- Конструктор копирования `Matrix(const Matrix& other)` создаёт независимую копию
  матрицы, включая все её элементы.
- Оператор присваивания `operator=` освобождает старую память, защищён от
  самоприсваивания и возвращает `Matrix&`, поэтому работает цепочка `d = e = a`.
- Пустые матрицы корректно копируются и присваиваются без выделения памяти.
- Домашнее задание выполнено: работа с памятью вынесена в приватные методы
  `allocate`, `copyFrom` и `freeMemory`.
- Сохранены методы заполнения, доступа к элементам, печати, вычисления суммы и
  транспонирования.

## Почему нет двойного освобождения памяти

Конструктор копирования и оператор присваивания выделяют для нового объекта
собственный массив строк и копируют значения поэлементно. Поэтому разные объекты
не владеют одним и тем же указателем `data_`. Метод `freeMemory` обнуляет указатель
и размеры после освобождения памяти, а проверка `this == &other` предотвращает
очистку объекта при самоприсваивании.

## Сборка и запуск

```powershell
g++ -std=c++17 -Wall -Wextra main.cpp Matrix.cpp -o lab4.exe
.\lab4.exe
```

Программа показывает независимость копии, обычное и цепочное присваивание,
самоприсваивание и работу с пустыми матрицами.
