# Лабораторная работа 3: Matrix

Проект реализует класс `Matrix` для динамически выделяемой прямоугольной матрицы
целых чисел. Данные матрицы хранятся построчно: сначала выделяется массив
указателей на строки, затем отдельно выделяется каждая строка.

## Возможности

- Конструктор по умолчанию создаёт пустую матрицу `0 x 0`.
- Конструктор с одним параметром создаёт единичную квадратную матрицу.
- Конструктор с двумя параметрами создаёт заполненную нулями матрицу заданного размера.
- Методы `get` и `set` проверяют индексы и при некорректном обращении бросают
  исключение `std::out_of_range`.
- При передаче отрицательной размерности генерируется исключение `std::invalid_argument`.
- Деструктор освобождает каждую строку, а затем массив указателей на строки.
- Метод `transpose` возвращает транспонированную матрицу.
- Демонстрационная программа заполняет матрицы по формуле, случайными числами и
  с клавиатуры, выводит их содержимое и показывает обработку обоих исключений.

## Сборка и запуск

```powershell
g++ -std=c++17 -Wall -Wextra main.cpp Matrix.cpp -o lab3.exe
.\lab3.exe
```

После запуска нужно ввести шесть целых чисел для матрицы размера `2 x 3`.

## Важное замечание о копировании

Копирование объекта `Matrix` намеренно не включено в штатный запуск. На этом этапе
у класса нет конструктора копирования и оператора присваивания, поэтому автоматически
созданная компилятором копия продублирует только указатель и приведёт к двойному
освобождению памяти. Это и есть результат эксперимента из домашнего задания;
управление копированием рассматривается в следующей части курса.
